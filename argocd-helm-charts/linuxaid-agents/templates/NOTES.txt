  operator:     {{ .Values.operator.image.repository }}:{{ .Values.operator.image.tag }}
  agent:        {{ .Values.agentImage.repository }}:{{ .Values.agentImage.tag }}
  certname:     {{ if .Values.certname }}{{ .Values.certname }}{{ else }}(NOT SET — the operator will exit immediately){{ end }}
  enforce:      {{ .Values.enforce }}{{- if .Values.enforce }} (APPLYING CHANGES){{ else }} (report-only){{ end }}
  interval:     {{ .Values.interval }}
  control-repo: {{ .Values.controlRepo.url }} @ {{ if .Values.controlRepo.ref }}{{ .Values.controlRepo.ref }}{{ else }}latest tag{{ end }}
  cert:         secret/{{ .Values.obmondoClientCert.secretName }}
  nodes:        {{ if .Values.nodeSelector }}selector "{{ .Values.nodeSelector }}"{{ else }}all nodes{{ end }}

Every {{ .Values.interval }} the operator lists nodes and creates one ephemeral privileged agent
Job per node (deterministic name, so a node whose Job is still running is skipped). No static
node list and no per-node CronJobs.

Prerequisites:
  * Deploy into the namespace holding {{ .Values.obmondoClientCert.secretName }} (e.g. obmondo); it must permit privileged pods (PSA).
  * The cluster must be able to pull both images (public on ghcr.io).
  * A private control-repo needs controlRepo.secretName set (key ssh-privatekey or token).

Watch:
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "linuxaid-agents.fullname" . }}-operator
  kubectl -n {{ .Release.Namespace }} get jobs -l app.kubernetes.io/name={{ include "linuxaid-agents.name" . }}

All nodes share the same certname (the obmondo-clientcert CN) => one puppet identity: fine for a
uniform role, not for per-node reporting. Start with enforce=false; flip to true once runs report
clean.
